# MusicHub 使用文档

## 网页版使用指南

### 启动

```bash
# 安装依赖 (仅首次)
pip install -r requirements.txt

# 启动网页版
python run.py

# 指定端口
python run.py --port 9000

# 仅本机访问
python run.py --host 127.0.0.1
```

### 功能说明

#### 搜索页
- 在搜索框输入关键词，按回车或点击搜索按钮
- 支持搜索建议（输入时自动弹出）
- 双击歌曲行播放，点击 ⬇ 按钮下载

#### 热门榜单
- 热歌榜 / 新歌榜 / 原创榜 切换
- 同样支持双击播放和单曲下载

#### 批量下载
- 设置下载数量 (1-200)
- 选择音质 (标准/高音质/无损)
- 快捷按钮: 5首/10首/20首/50首/100首
- 点击"开始随机下载"，从热歌榜随机选取歌曲下载
- 实时显示下载进度

#### 本地曲库
- 查看已下载歌曲数量和占用空间
- 显示下载目录路径

#### 其他版本
- 各平台下载链接和安装指南

### 播放器

底部固定播放器支持:
- 播放/暂停
- 上一首/下一首
- 进度条拖拽
- 音量调节

## 命令行版使用指南

### 启动

```bash
# 交互模式
python run.py --cli

# 或直接运行
python cli/main.py
```

### 命令一览

| 命令 | 缩写 | 说明 | 示例 |
|------|------|------|------|
| search | s | 搜索歌曲 | `s 周杰伦` |
| hot | | 热歌榜 | `hot` |
| new | | 新歌榜 | `new` |
| play | p | 播放 (显示链接) | `p 3` |
| download | dl | 下载歌曲 | `dl 3` |
| dlall | | 下载当前列表全部 | `dlall` |
| random | rand | 随机下载热门 | `random 10` |
| playlist | pl | 查看歌单 | `pl 3778678` |
| stats | | 下载统计 | `stats` |
| help | | 帮助 | `help` |
| quit | q | 退出 | `q` |

## Windows EXE 使用

1. 下载 `MusicHub.exe`
2. 双击运行
3. 自动打开浏览器访问 `http://localhost:8888`
4. 关闭时关闭命令行窗口即可

## QQ 机器人插件使用

### AstrBot

在 QQ 中发送:
```
/music search 周杰伦
/music hot
/music download 1234567
/music random 10
/music playlist 3778678
```

### NoneBot2

同上命令格式，也支持中文别名:
```
/音乐 search 周杰伦
/点歌 热歌榜
```

## 配置说明

编辑 `config.py` 修改配置:

```python
# 服务端口
PORT = 8888

# 下载目录
DOWNLOAD_DIR = "~/MusicHub/downloads"

# 默认音质
DEFAULT_QUALITY = "exhigh"  # standard/exhigh/lossless/hires

# 请求间隔 (防限流)
REQUEST_INTERVAL = 0.5
```
